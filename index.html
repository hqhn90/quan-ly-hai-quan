Google Sheets trực tiếp

Bạn có thể thao tác trực tiếp trong bảng phía dưới. Quyền sửa do Google quản lý. Nếu bị chặn nhúng, hãy nhấn nút Mở Google Sheets ở phía trên.

⚙ Cấu hình Google Sheets API (không sử dụng Apps Script)

Để các nút sửa/xóa/lưu trong file HTML hoạt động trên Google Sheets, cần có OAuth Client ID của Google Cloud. Chỉ bật “Bất kỳ ai có liên kết được chỉnh sửa” là chưa đủ để HTML truy cập API. Mỗi người dùng đăng nhập bằng tài khoản Google có quyền sửa bảng. Google Cloud OAuth đối với file HTML mở bằng file:// không hoạt động: cần đưa HTML lên một địa chỉ HTTPS (ví dụ GitHub Pages hoặc máy chủ nội bộ HTTPS), thêm địa chỉ đó vào Authorized JavaScript origins của OAuth client loại Web application, bật Google Sheets API và điền Client ID phía dưới. Không cần dùng khóa API hay cung cấp mật khẩu.

Bật Sheets APITạo OAuth Client ID

Sau khi F5, ứng dụng sẽ thử khôi phục đăng nhập. Nếu Google yêu cầu xác thực lại, bấm Kết nối tài khoản Google; không lưu token bí mật dài hạn. Cấu hình này chỉ được lưu tại trình duyệt đang dùng. Không công khai token truy cập. Không cần bật công khai quyền chỉnh sửa cho toàn bộ Internet; chỉ cấp quyền cho công chức được phép.

Bản công khai trên GitHub không chứa công việc trong mã nguồn; khi đăng nhập, phần mềm mới đọc dữ liệu từ Google Sheets. Thao tác thêm / sửa / xóa chỉ thông báo thành công sau khi Google xác nhận.
